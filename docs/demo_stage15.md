# Этап 15: демонстрация и автоматизация

Реализованы demo.py, scripts/start_rag.ps1, scripts/stop_rag.ps1 и три роли Spark.
Spark подготовил черновики скриптов и README; ведущий исправил пути, аргументы,
идентификацию процесса и перепутанные hybrid/reranked метрики. Проверки Spark
заблокированы политикой: ведущий выполнил команды, Spark проверил переданные логи.

Финальные проверки: 157 passed (17.75 s), mypy strict 30 файлов, Ruff без ошибок.
PowerShell AST обоих скриптов разобран без ошибок. Конфигурации разобраны tomllib.

Реальный запуск start_rag.ps1 -Preset rfc-01 создал индекс из 3 документов,
1674 чанков, затем выдал ответ о HTTP 204 с [S1]. NLI подтвердил утверждение.
Время запроса 9099.9 мс; первичная загрузка retriever и индексация выполнялись
до query и не входят в эту цифру. TTFT не измерялся и так помечен в интерфейсе.
Повторный start_rag.ps1 -IndexOnly из C:/Users/Egoru вернул reused: 1674.
Экспорт: .artifacts/stage15/demo.json и demo.html (автономный HTML).

Полностью автоматическая остановка не реализована: запись варианта с принудительным
завершением была отклонена автоматической проверкой без подробного основания.
Текущий stop проверяет PID/путь/время и пробует CloseMainWindow. Для скрытого
консольного процесса возвращает ошибку с PID для ручной остановки. Не считать
это подтверждённым graceful shutdown. Холодный старт не проверен: сервер уже работал.

Исходные метрики holdout сохранены: Hit@5 100%, положительные ответы 5/7,
негативные отказы 3/3. Это исторический AI-размеченный набор, а не новая оценка
точности интерфейса. Порогов и промптов этап 15 не меняет.
