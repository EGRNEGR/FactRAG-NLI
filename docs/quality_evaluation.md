## Выявленные ограничения

1. У `rfc-04`, `pg-03`, `nist-03` генератор вернул `finish_reason=context_budget`:
   выбранные чанки не поместились в консервативный UTF-8 byte budget. У ряда других
   запросов были исключены отдельные источники. При размере окна 4096 наличие
   найденного чанка не гарантирует, что он будет передан LLM.
2. NLI отклоняет многие русские формулировки по английским источникам. В частности,
   в ответе о 403 обнаружены высокие contradiction/neutral вероятности. Нельзя
   интерпретировать их как экспертное доказательство ошибочности перевода.
3. Реранкинг/порог снижает Hit@5. Порог не изменялся ради улучшения результата.
4. Парсер RFC местами принимает нумерованные списки за заголовки разделов;
   HTML-преобразование сохраняет часть навигационного текста. Это наблюдаемые
   направления улучшения preprocessing перед повторным экспериментом.

Следующие работы по качеству: точная локальная токенизация для упаковки контекста,
отдельная валидация NLI на англо-русских парах, экспертная проверка релевантности
и негативов, затем калибровка поиска на отдельной development-выборке.
Тестовую разметку и пороги нельзя совместно подгонять по этим 15 вопросам.
