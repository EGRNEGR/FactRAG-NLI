## Этапы 1 и 7

- scripts/verify_environment.py выводит единый JSON и код 0/1; проверяет контейнеры
  Safetensors/PyTorch/GGUF, классификатор, токенизатор, RAM/VRAM, свободное место,
  реальную запись в каталоги, открытие Qdrant, внешние DNS/TCP-пробы.
  SHA-256 записывается для воспроизводимости, но не сверяется с доверенным манифестом.
- Поддержаны имена environment/mode и qdrant_storage_path/qdrant_path.
- HybridRetriever использует RAGSettings, настоящий embedded Qdrant, BM25Okapi,
  Unicode-токенизацию без внешних словарей, weighted RRF и локальный реранкер.
- BGE-M3 загружается через SentenceTransformer с его modules.json (без неявного
  mean pooling). Реранкер использует AutoModelForSequenceClassification;
  отсутствующие параметры запрещены, скоры нормализуются sigmoid.
- В production нет автоматической подмены моделей. Development-fallback требует
  явного флага и регистрирует причину; сбой базы не включает запасное хранилище.
- Qdrant хранит полный payload, контекст таблиц/сносок и подпись эмбеддингов.
  Смена модели/размерности требует новой коллекции. BM25 хранит безопасный JSON
  токенизированного корпуса, восстанавливает статистики при открытии. Повреждённый,
  отсутствующий или устаревший кэш пересоздаётся из Qdrant; pickle не используется.
- Запись сериализована. При ошибке после изменения Qdrant объект блокирует
  дальнейшие операции до повторного открытия. Есть upsert, delete_document и close.
- Embedded Qdrant рассчитан на одного владельца каталога; API должен закрывать
  ретривер при shutdown и не запускать несколько workers с одним каталогом.

## Ограничения

- Старые generator, API и benchmark ещё не мигрированы на RAGSettings.
  Эвристики в них остаются. Полный конвейер не прошёл приёмку production.
- Проверяется комплектность весов, а не SHA-256 по доверенному манифесту
  и не успешная загрузка тензоров. Локальные веса не предоставлены.
- PDF без текста требует отдельного локального OCR. Извлечение таблиц зависит
  от геометрии документа. Несвязанные продолжения отмечаются unresolved;
  произвольная сложная вёрстка не проверена на реальном корпусе.
- DOCX не содержит надёжной пагинации: page_start/page_end остаются null,
  лимит 500 страниц проверяется для PDF. Для DOCX потребуется локальный рендер.
- Многоуровневые заголовки DOCX объединяются, когда строки объявлены tblHeader;
  неразмеченные строки сохраняются буквально. В PDF сохраняются raw_cells
  и header_names; семантика произвольного составного заголовка требует проверки.
- Примечания связываются по разделу, сноски — по маркеру и странице,
  если она известна. Это структурная привязка, не доказательство применимости нормы.
- Проверка resolve не защищает от конкурентной подмены файлов другим процессом.
- Нейросетевой benchmark и нагрузочные измерения не запускались; метрики качества
  отсутствуют. Для этапов 4–5 необходимы реальные документы и проверенная разметка.

## Проверка

Создана .venv (Python 3.14); выполнение на 3.11 не проверялось, хотя код
использует синтаксис 3.11 и проверяется mypy для 3.11.
requirements-parser.lock.txt фиксирует пакеты тестовой среды, не весь RAG-стек.

```powershell
.\.venv\Scripts\python -m pytest
.\.venv\Scripts\python -m mypy settings.py document_parser.py
.\.venv\Scripts\python -m ruff check settings.py document_parser.py tests/test_settings.py tests/test_document_parser.py tests/conftest.py
```

Проверки этапов 1/7: 62 теста (реальные Qdrant/BM25/PDF/DOCX; нейросетевые
загрузчики проверены на уровне аргументов и отказов), mypy strict по шести
новым/изменённым модулям, Ruff, pip check. Реальные BGE-M3/reranker не загружались:
весов и PyTorch нет. Аудит текущего окружения вернул 1: не настроены API-токены,
отсутствуют четыре набора весов. Запись каталогов, RAM и Qdrant проверены успешно.
Полный результат: .artifacts/environment-audit.json.

RAG_NETWORK_POLICY=local_only допускает доступную сеть при запрете скачивания
моделей локальными загрузчиками. RAG_NETWORK_POLICY=air_gap требует наблюдаемого
отказа DNS для обоих хостов. Ни один режим не сертифицирует firewall или физическую
изоляцию; таймаут сам по себе не считается доказательством.

Запуск новых проверок:

```powershell
.\.venv\Scripts\python scripts/verify_environment.py
.\.venv\Scripts\python -m mypy settings.py document_parser.py hybrid_retriever.py scripts/verify_environment.py tests/test_hybrid_retriever.py tests/test_verify_environment.py
```

Зависимости: pyproject.toml extras retrieval,audit; requirements-retrieval-tests.lock.txt
фиксирует фактически установленную тестовую среду, без нейросетевого runtime.
Для переноса в изолированный контур подготовьте wheelhouse на совместимой платформе;
не запускайте сетевую установку пакетов внутри air-gap.
