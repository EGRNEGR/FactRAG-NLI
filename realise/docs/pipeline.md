# Этап 10: сквозной конвейер

`pipeline.RAGPipeline` принимает `RAGSettings`, лениво создаёт компоненты и
поддерживает `with` / `close()`. Закрытие выполняется для всех созданных компонентов,
даже если один из них завершился с ошибкой. Один экземпляр последовательно
обрабатывает операции под блокировкой; embedded Qdrant требует одного владельца.

## Запуск

Из корня проекта, с настроенным `.env` и работающим локальным llama-server:

```powershell
.\.venv\Scripts\python baseline_rag.py --index .\documents
.\.venv\Scripts\python baseline_rag.py --query "Какое допустимое давление?"
.\.venv\Scripts\python baseline_rag.py --query "Какое допустимое давление?" --json
.\.venv\Scripts\python baseline_rag.py --benchmark --benchmark-file .\questions.json
```

Каталог индексации должен находиться внутри `RAG_DOCUMENT_ROOT`. Поддержаны PDF,
DOCX, TXT и MD с рекурсивным обходом. `questions.json` — непустой JSON-массив строк.
Без файла используются три примерных вопроса про давление, температуру и исключения.
`--index`, `--query` и `--benchmark` можно объединить в одном запуске.
Цветные статусы включаются в терминале, `--no-color` отключает их.

## Контракты

- `index_documents(list[Path])` возвращает `IndexingStats`: файлы, чанки,
  время и идентификаторы документов. Повторяющиеся пути учитываются один раз.
  Пути проверяются до записи, затем документы фиксируются по одному. При сбое
  `IndexingError.stats` содержит уже завершённую часть; общей транзакции пакета нет.
- Индексы сохраняются на диске. `pipeline.documents` содержит только документы,
  разобранные в текущем процессе, и не является полным каталогом постоянной базы.
- `query()` возвращает Pydantic `RAGResponse` с ответом, типизированными источниками,
  всеми проверенными/отфильтрованными утверждениями и временем этапов в миллисекундах.
  `model_dump(mode="json")` и `model_dump_json()` дают сериализуемый результат.
- Источники сохраняют идентификаторы `[Si]` и соответствуют контекстам, действительно
  переданным генератору. Сохраняются dense, sparse, RRF и rerank scores.
- При отсутствии кандидатов выше порога возвращается канонический отказ без
  загрузки/вызова LLM и NLI. Ошибки компонентов не подменяются фактическим отказом.
- `faithfulness_score` — доля подтверждённых утверждений среди всех исходных
  утверждений ответа; это диагностическая доля NLI, а не результат оценки Ragas.
- `RAG_MAX_QUESTION_CHARS` задаёт лимит вопроса (по умолчанию 4000). Нормализация,
  запрет управляющих символов и фильтр известных шаблонов подмены инструкций
  ограничивают вход, но не доказывают отсутствие произвольной prompt injection.

`search_ms` исключает время cross-encoder; оно записано в `rerank_ms`.
`generation_ms`, `nli_ms`, `model_init_ms`, `total_ms` измеряются отдельно.
`--benchmark` сохраняет отказы и ошибки, wall time и p50/p95, включая холодный
старт. Это замер задержек текущего гибридного конвейера; dense-only baseline,
экспертная разметка и научные метрики качества требуют отдельного эксперимента.

## Проверка 2026-09-05

Итог: 119 тестов пройдены; mypy `--strict` — без ошибок в 19 файлах;
`ruff check .` — без ошибок. Один warning PyTorch о неподдерживаемом sm_120.

Интеграционные тесты используют реальный парсер, embedded Qdrant и BM25,
явные диагностические encoder/reranker и управляемые ответы генератора/NLI.
Проверены файл → ответ, сохранение метаданных, повторная индексация и перезапуск,
отказ без LLM, блокировка неподтверждённых утверждений, валидация вопроса,
частичная ошибка пакета, освобождение хранилища и CLI в отдельном процессе.

Дополнительно выполнен локальный нейросетевой smoke-прогон на одном искусственном
документе с BGE-M3, bge-reranker-large, Qwen через llama-server и mDeBERTa NLI.
Вопрос «Допустимое давление составляет 10 МПа?» дал ответ
«Допустимое давление составляет 10 МПа [S1].»: rerank 0,99824,
NLI entailment 0,93612, подтверждена 1 из 1 фраз. Порог реранкера 0,5 не менялся.
Полное время запроса около 4,77 с, включая инициализацию LLM/NLI около 1,94 с.
Более короткий вопрос «Какое допустимое давление?» был отсечён на этапе поиска.
Оба результата сохранены в `.artifacts/pipeline-smoke/`; это не приёмка на корпусе.

Нейросетевые Python-компоненты работали на CPU: установленный PyTorch не
поддерживает sm_120 этой GPU. Генерация использовала уже запущенный llama-server.
Добавлена совместимость локального загрузчика с SentenceTransformers 5/6.

```powershell
.\.venv\Scripts\python -m pytest
.\.venv\Scripts\python -m mypy --strict settings.py document_parser.py hybrid_retriever.py generator_verifier.py pipeline.py baseline_rag.py app.py benchmark_ragas.py scripts tests
.\.venv\Scripts\python -m ruff check .
```
