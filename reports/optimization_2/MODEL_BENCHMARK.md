(PAIRED_ERROR_ANALYSIS.md). Qwen2.5-14B быстрее в 1.6 раза, но даёт в 9 раз больше

полезен (14 исправленных ответов), для Qwen3.8 нет (0), см. BASELINE.md. Рассуждение «всегда»
дороже гибрида в 2.6 раза по времени генерации и хуже его по точности (1147 против 1174).

сеанса; рядом с вторым NLI-моделем слоя решений места для него нет.

## NLI-модели

Повтор 0508Z с гибридом (маршрутизатор A), модель - единственный классификатор в правилах
верификатора v2 (V10) или вторая модель слоя решений (V30). «Ложные: ...» - доля принятых
синтетических ложных утверждений test. Скорость - RTX 5060 Laptop, fp16, 7708 реальных пар
из 300 черновиков (медиана 24 пары на черновик); на 3090 примерно вдвое быстрее.

VRAM - пик torch.cuda при оценке пар (веса fp16 и активации). Для отдельных моделей
FactRAG пессимистичен на 14-17 вопросов (нет исправлений, см. NLI_VERIFIER_RESEARCH.md); для
слоя решений исправления сгенерированы.

Одна модель NLI любого из проверенных размеров не лучше mDeBERTa по надёжности: модели XNLI
большого размера принимают подменённые ответы и отрицания ещё чаще. Выигрыш даёт только
сочетание моделей с разными ошибками в калиброванном решении. Выбрана пара mDeBERTa +
bge-m3-zeroshot-v2.0: обе MIT, вторая обучена на двухклассовом NLI с длинным контекстом
(8192) и почти не пропускает утверждения не по теме (пересадка 1.2%).

| Компонент | VRAM | Источник цифры |

Итог для слоя решений - около +0.1 ГБ к пику 0508Z, то есть тот же запас. Цена переноса
кодировщика запросов на CPU - 61 мс на вопрос (медиана на CPU ноутбука, p90 71 мс); индекс
строится стадиями поиска на GPU до запуска llama-server. NLI двумя моделями: ~0.14 с на
черновик на ноутбуке (оценка для 3090 - около 0.07 с) против 4-20 с генерации.
