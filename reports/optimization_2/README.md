# optimization_2: FactRAG-NLI 2.0

Исследование и оптимизация по логам полного прогона 20261031T0508Z (RTX 3090, 1307 вопросов).
Начинать с `FINAL_REPORT.md`.

| Файл | Содержание |
|---|---|
| FINAL_REPORT.md | итог: исходные и лучшие метрики, первопричины, изменения, достоверность, производительность, VRAM, остаточные проблемы, команда запуска |
| FINAL_ARCHITECTURE.md | поток запроса лучшей конфигурации, что включено и что отклонено, память |
| BEST_CONFIG.yaml | все параметры лучшей конфигурации и ожидаемые метрики |
| BASELINE.md | воспроизведение базовой линии по логам, все конфигурации 0508Z |
| PAIRED_ERROR_ANALYSIS.md, error_analysis/ | попарный анализ Vanilla/FactRAG, CSV по каждому вопросу, ручной разбор |
| NLI_VERIFIER_RESEARCH.md | верификатор v2, стресс-набор, варианты, альтернативные модели, слой решений |
| SELECTIVE_THINKING_RESEARCH.md | поводы для рассуждения A-G, правка вместо нового черновика, восстановление |
| ADAPTIVE_RETRIEVAL_RESEARCH.md | слияние и выбор реранкера, адаптивный контекст, гейт |
| CALIBRATION_REPORT.md | калибровка вероятностей утверждений и ответов |
| MODEL_BENCHMARK.md | LLM, реранкеры, NLI-модели: качество, скорость, VRAM, лицензии |
| EXPERIMENTS.csv, experiments/ | реестр экспериментов с верификатором (настройки, время, VRAM, метрики, ошибки) |
| METRICS_COMPARISON.csv, final/ | сравнение кандидатов архитектуры с доверительными интервалами |
| judge/, calibration/, routing/, retrieval/, speed/ | исходные данные таблиц |
| live_check/ | живой прогон лучшей конфигурации на ПК разработки (11 вопросов) |

Код: `research/opt2/`; повтор всего исследования - `python -m research.opt2.reproduce --run
<папка прогона 0508Z>`. Запуск лучшей конфигурации на 3090 - `PLAN=main bash
scripts/linux/run_benchmark.sh`, установка на другой ПК - `docs/SECOND_PC_RTX3090.md`.
