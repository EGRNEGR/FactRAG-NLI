### G3: перевод вопроса и повторный поиск после отказа

Популяция - 151 вопрос:
- **по причине отказа:** гейт 90, отказ LLM 61;
- **по датасету:** XQuAD 125, v3 26;
- **по ожиданию:** отвечаемых 38, неотвечаемых 113.

Что произошло после перевода:

| | Отвечаемые (38) | Неотвечаемые (113) |
|---|---|---|
| гейт не пройден | 4 | 71 |
| гейт пройден, LLM снова отказала | 29 | 42 |
| ответ опубликован | **5** | **0** |

Все 5 опубликованных ответов - на английские вопросы к русскому корпусу:

| Вопрос | Split | Отказ в 1310Z | Перевод | Ответ | Оценщик |
|---|---|---|---|---|---|
| V3-XQFEN-031 «Who stripped the ball from Newton on a 3rd and nine?» | test | LLM | «Кто выбил мяч у Ньютона на 3-м дауне с 9 ярдами до первой отметки?» | «Миллер забрал мяч у Ньютона» | верно |
| V3-XQFEN-065 «Who do gurus control?» | test | LLM | «Кем управляют гуру?» | «Гуру управляют своими послушниками» | верно |
| V3-XQFEN-245 «What are two examples of primitive jawless vertebrates?» | dev | LLM | «Каковы два примера примитивных челюстных позвоночных?» | «Примитивными челюстноротыми являются миноги и миксины» | верно |
| V3-XQFEN-291 «When was the divestment from South Africa movement?» | dev | гейт | «Когда произошло движение за вывод инвестиций из Южно-Африканской Республики?» | «... произошло в конце 1980-х годов» | верно |
| V3-XQFEN-320 «What are longer growth spells associated with?» | dev | гейт | «С чем связаны более длительные периоды роста?» | «... тесно связаны с большим уровнем равенства при распределении доходов» | **не засчитан** |

Пояснения к таблице:
- **V3-XQFEN-320 - промах оценщика.** Ответ дословно совпадает с эталоном «бoльшим уровнем равенства ...». В эталоне и в тексте XQuAD «бoльшим» написано с латинской «o» (U+006F), поэтому правило `бoльш\w*` не находит кириллическое «большим». Такой эталон в датасете ещё один (V3-XQFEN-247). Метки не менялись: прирост по оценщику +4, фактически верных ответов 5.
- **V3-XQFEN-065 - утверждение сильнее источника.** В источнике «гуру имеют огромное влияние на своих послушников». Ответ повторяет предикат вопроса «управляют», и судья принял его с вероятностью следования 0.979. Эталон XQuAD этот ответ принимает. Это мягкость NLI на перефразе, а не ошибка перевода; G3 её только проявил.
- **V3-XQFEN-245:** перевод вопроса неточен («челюстных» вместо «бесчелюстных»). Ответ точно повторяет источник, а ошибка «челюстноротых» сидит в переводе текста XQuAD (диагностика: dataset_noise).
- **Упорные отказы:** из 52 упорных отказов в популяцию попали 24, все английские. 28 русских G3 не затрагивает по построению: алфавит вопроса совпадает с алфавитом источников. Исправлены 2 (V3-XQFEN-065, V3-XQFEN-245). 5 вопросов с лексическим расхождением EN-RU в популяции есть, но ни один не исправлен: перевод LLM не попадает в термин текста. Остальные 3 исправления вне этой выборки: V3-XQFEN-291 и V3-XQFEN-320 - отказы гейта (попыток LLM не было), у V3-XQFEN-031 черновики давали утверждения, которые отклоняла проверка.

**Критерии принятия (задача 4) на уровне шагов:**

| Критерий | G3 |
|---|---|
| прирост | +4 / -0 по оценщику (5 верных фактически), McNemar p = 0.125 на популяции |
| новые галлюцинации | 0: неотвечаемых опубликовано 0 из 113, хотя 42 из них после перевода прошли гейт |
| потери | 0 (вне популяции ответы не меняются по построению) |
| dev | +2 / -0 по оценщику, +3 фактически |
| проекция на все 1307 вопросов | 1188 / 1307 (90.9%), ложные отказы 79 -> 74, галлюцинации 3 / 269 |
| стоимость | 1 вызов перевода на 151 вопрос из 1307, ещё 1 черновик там, где гейт пройден (76): 7.2 минуты на прогон |

Что ограничивает вывод:
- Прирост мал, p = 0.125.
- Безопасность на 42 неотвечаемых, прошедших гейт после перевода, держится только на отказе LLM.

Поэтому G3 встроен в конвейер, но не включён в рабочую конфигурацию до подтверждения настоящим конвейером.

**Перенос в конвейер проверен повтором.** Поддельная LLM отвечала ровно теми переводами и черновиками, что записаны на 3090. На них:
- исследовательский шаг G3 после рефакторинга воспроизвёл живую сводку (151, 5 замен, +4 / -0, 0 расхождений по решениям, текстам и гейту);
- новый путь `RAGPipeline` с `query_translation=refusal` принял те же решения по всем 151 вопросу.

Значит, `PLAN=g3` проверяет тот же G3, а не другую реализацию.

### G4: нормализация вопроса после отказа LLM

В популяцию вошли 140 вопросов, среди них все 52 упорных отказа:
- 85 вопросов модель вернула без изменений; повторной генерации не было;
- 55 вопросов изменены, но только косметически: «по SP 800-63B-4» -> «согласно SP 800-63B-4», «use» -> «utilize»;
- все 55 снова получили отказ.

Итог +0 / -0. Гипотеза H1 в этой форме **опровергнута**: формулировка вопроса не причина отказов LLM. Искажённые переводом XQuAD вопросы (7) модель не распознаёт как искажённые.

## 6. Изменения кода

- **`query_translation.py` (новый).** Детектор алфавита, промпт перевода, разбор ответа и триггеры. Перенесены из `research/opt4/steps.py` без изменений: шаг G3 импортирует их оттуда же.
- **`pipeline.py`:**
  - `query()` = `_answer()`, затем при `query_translation=refusal` вызывается `_translated()`;
  - проходы после черновика вынесены в `_passes()`, ленивая загрузка моделей - в `_models()`;
  - с флагом "off" путь вопроса прежний;
  - в `RAGResponse` добавлено поле `translation` (переведённый вопрос, целевой алфавит, сырой ответ, время, причина отказа переведённого ответа);
  - опубликованный переведённый ответ сохраняет исходный `query` и все попытки обоих проходов.
- **`generator_verifier.py`:** `LocalLLMGenerator.rewrite()` - один вызов без источников и без рассуждения.
- **`settings.py`:** `query_translation: "off" | "refusal"`, по умолчанию "off".
- **`evaluate_suite.py`:** `translation_pass` в строке вопроса, блок `translation_pass` в сводке e2e, `query_translation` в config.json прогона.
- **`research/opt4/compare.py`:** популяция `G3` (триггер шага G3, совпадает с живой популяцией 151 из 151), разбиение dev/test.
- **`research/opt4/live_analysis.py` (новый):** разбор шагов G3 и G4 по вопросам -> `analysis.json`.
- **`research/opt4/steps.py`:** `plan` считает только выбранные эксперименты. Раньше для `quick` он суммировал и G2: 22.5 мин вместо 17.9.
- **`research/opt4/live_report.py`:** строки e2e по dev и test.
- **`scripts/linux/run_experiments.sh`:** `PLAN=g3`.
- **Ранее в optimization_4:**
  - `nli_anchor_scope`, `nli_premise_unwrap_tables`;
  - `evaluate_suite.py --ids`;
  - загрузчики `research/opt3/data.py` без git;
  - `research/opt4/` (diagnose, report, annotations.json, offline, retrieval, metrics, steps).
- **Тесты:**
  - новый `tests/test_query_translation.py` (7): оба триггера, выключенный флаг, вопрос на языке источников, отказ после перевода, опубликованный ответ не переводится;
  - в подделку ответа `tests/test_e2e_watchdog.py` добавлено поле `translation`;
  - весь набор: 321 прошли, 1 пропущен (POSIX-only на Windows).

  - E4 (поиск по частям правилом);
  - E5 без триггера (цена);
  - ослабление правила предпосылки и подсказка о перефразе (этапы 2-3).
- **G2** не проверен.

## 9. Оставшиеся проблемы

- **Модальные утверждения и переводы с отрицанием.** «MAY», «может» и переводы с «SHALL NOT» получают низкую оценку NLI на верном тексте: V3-MH-002, V3-MH-018. Нужна работа с NLI-моделью, а не с конвейером.
- **Мягкость NLI на перефразе, обратная сторона того же.** «управляют» принято по «имеют огромное влияние» (V3-XQFEN-065, 0.979).
- **Лексическое расхождение EN-RU** (5 упорных отказов) переводом LLM не лечится: перевод не попадает в термин текста.
- **Единственная настоящая галлюцинация V3-ADV-029** (74 бита rand_b) осталась. E1 и G3 её не затрагивают.
- **Оценщик XQuAD:**
  - засчитывает ошибкой обоснованные отказы (14 вопросов «текст не утверждает»);
  - не находит ответ, если в эталоне латинские буквы внутри русского слова (V3-XQFEN-320, V3-XQFEN-247).
  Эталоны не менялись по правилам задачи.
- **Сегментатор** делит «Y. pestis» на утверждение «p.» (V3-XQFEN-163). Правка мелкая, вне плана.
