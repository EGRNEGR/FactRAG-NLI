# FactRAG-NLI
Локальная RAG-система для технической документации со встроенной проверкой фактов. Использует LLM для ответов и NLI-модель для оценки достоверности каждого утверждения. Обеспечивает гибридный поиск, точное цитирование источников, инкрементальную загрузку файлов (PDF, DOCX) и полную автономность без риска утечки конфиденциальных данных.
